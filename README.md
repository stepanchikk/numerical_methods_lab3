## 🎯 Мета

Ознайомитися з чисельними методами розв'язування нелінійних систем і набути практичних навичок розв'язання таких задач, зокрема з використанням комп'ютера.

## 📋 Умова (варіант 7)

Знайти наближений розв'язок нелінійної системи з точністю $\varepsilon = 10^{-3}$:

$$
\begin{cases}
x + \cos y = 1{,}5,\\
2y - \sin(x - 0{,}5) = 1
\end{cases}
$$

- ☐ методом Ньютона;
- ☐ методом простої ітерації;
- ☐ методом Зейделя.

## 🧭 План виконання

### Етап 1. Підготовка системи — *Степан*
- Звести систему до вигляду $F(x) = 0$: перенести вільні члени вліво, позначити $x_1 = x$, $x_2 = y$.
- Описати функції $f_1$, $f_2$ та параметри задачі ($\varepsilon$, максимальна кількість ітерацій).

### Етап 2. Локалізація розв'язку — *Степан*
- Побудувати графіки обох рівнянь на площині.
- Визначити прямокутник $G$, у якому лежить розв'язок, і обрати початкове наближення $x^{(0)} \in G$ (одне для всіх трьох методів).
- Зберегти графік у `results/`.

### Етап 3. Метод Ньютона — *Олександр*
- Скласти матрицю Якобі $W(x)$ системи $F(x) = 0$.
- На кожному кроці розв'язувати СЛАР $W(x^{(k-1)})\,\Delta^{(k)} = -F(x^{(k-1)})$ і обчислювати $x^{(k)} = x^{(k-1)} + \Delta^{(k)}$.
- Зупинка: $\max\{|x_1^{(k)} - x_1^{(k-1)}|,\ |x_2^{(k)} - x_2^{(k-1)}|\} \le \varepsilon$.
- Зберігати дані кожної ітерації для таблиці.

### Етап 4. Ітераційний вигляд і умова збіжності — *Степан*
- Звести систему до вигляду $x = \Phi(x)$: $x_1 = \varphi_1(x_1, x_2)$, $x_2 = \varphi_2(x_1, x_2)$.
- Скласти матрицю Якобі $\dfrac{\partial\Phi}{\partial x}$ та оцінити $q = \max\limits_{x \in G}\left\|\dfrac{\partial\Phi}{\partial x}\right\|$ (по рядках або по стовпцях).
- Переконатися, що $q < 1$ (достатня умова збіжності МПІ та Зейделя).
- Визначити умову зупинки: $\Delta^{(k)} \le \frac{1-q}{q}\varepsilon$, якщо $q > 0{,}5$, або $\Delta^{(k)} \le \varepsilon$, якщо $q \le 0{,}5$.

### Етап 5. Метод простої ітерації — *Даниїл*
- Ітерації за формулами $x_1^{(k)} = \varphi_1(x_1^{(k-1)}, x_2^{(k-1)})$, $x_2^{(k)} = \varphi_2(x_1^{(k-1)}, x_2^{(k-1)})$.
- Умова зупинки з етапу 4.
- Зберігати дані кожної ітерації для таблиці.

### Етап 6. Метод Зейделя — *Тарас*
- Ітерації за формулами $x_1^{(k)} = \varphi_1(x_1^{(k-1)}, x_2^{(k-1)})$, $x_2^{(k)} = \varphi_2(x_1^{(k)}, x_2^{(k-1)})$ — для другої координати одразу береться нове $x_1^{(k)}$.
- Умова зупинки з етапу 4.
- Зберігати дані кожної ітерації для таблиці.

### Етап 7. Перевірка, порівняння, звіт — *Степан*
- Підставити знайдені розв'язки у вихідну систему (нев'язки мають бути меншими за $\varepsilon$).
- Порівняти методи за кількістю ітерацій.
- Написати звіт.

### Як `main.py` поєднує частини

`main.py` по черзі викликає:

1. локалізацію та оцінку збіжності — `src/localization.py` *(Степан)*;
2. метод Ньютона — `src/newton.py` *(Олександр)*;
3. метод простої ітерації — `src/simple_iteration.py` *(Даниїл)*;
4. метод Зейделя — `src/seidel.py` *(Тарас)*;
5. перевірку розв'язків і порівняльну таблицю *(Степан)*.

### Домовленість про інтерфейс

Щоб `main.py` працював однаково з усіма методами, кожен метод має функцію `solve(...)`, яка:
- приймає початкове наближення `x0 = (x, y)` і точність / поріг зупинки;
- повертає `(x, y, records)`, де `records` — список ітерацій, кожна з полями `k`, `x`, `y`, `dx`, `dy`, `delta`.

Таблиця ітерацій у звіті має такі колонки (як у методичці):

| k | $x_1^{(k)}$ | $x_2^{(k)}$ | $\|x_1^{(k)}-x_1^{(k-1)}\|$ | $\|x_2^{(k)}-x_2^{(k-1)}\|$ | $\Delta^{(k)}$ | Висновок |
|---|---|---|---|---|---|---|
